这是一份为您量身定制的 **Vue 3 + TypeScript 技术选型落地清单**。未来启动新项目时，您只需根据项目类型（PC端、移动端、或需要SEO），直接在对应分类中“勾选”即可。

------

## 🚀 Vue 3 + TS 项目技术选型清单

## 1. 核心铁三角（必选）

- **[ ] 核心框架：** `Vue 3` (使用 Composition API + `<script setup>` 语法)
- **[ ] 路由管理：** `Vue Router 4` (支持 TS 类型化的路由)
- **[ ] 状态管理：** `Pinia` (轻量、原生支持 TS，替代 Vuex)

## 2. 开发与构建工具（必选）

- **[ ] 构建工具：** `Vite` (官方标配，秒级热启动，基于原生 ESM)
- **[ ] 编程语言：** `TypeScript` (严格模式 `strict: true`，确保类型安全)
- **[ ] 包管理器：** `pnpm` (推荐，节省磁盘空间，安装速度极快)

## 3. UI 组件库（根据应用场景 3 选 1）

- [ ] 场景 A：PC 端后台管理/企业应用
  - `Element Plus` (国内生态最好，后台系统首选)
  - `Ant Design Vue` (设计感更现代，适合中后台应用)
- [ ] 场景 B：移动端 H5 / 小程序
  - `Vant` (轻量、可靠的移动端 Vue 组件库)
  - `NutUI` (京东出品，对电商、移动端表现优秀)
- [ ] 场景 C：极致自定义样式/前台官网
  - `Tailwind CSS` (原子化 CSS，不提供组件封装，但样式定制极度自由)

## 4. 必备效率工具库（强烈推荐）

- **[ ] 工具函数集：** `VueUse` (基于组合式 API 的神级工具库，必装)
- **[ ] 网络请求：** `Axios` (搭配 TS 封装统一的 Request 拦截器)
- **[ ] 图标库：** `Iconify` 或 `Element Plus Icons` (按需引入，拒绝臃肿)

## 5. 代码质量与规范（团队开发必选）

- **[ ] 语法检查：** `ESLint` (采用最新的 Flat Config 扁平配置)
- **[ ] 代码格式化：** `Prettier` (与 ESLint 配合，一键保存自动对齐)
- **[ ] Git 提交规范：** `husky` + `lint-staged` (在 Git Commit 时强制格式化，防止烂代码入库)

## 6. 特殊场景选配（按需选择）

- **[ ] SSR / SEO 需求：** `Nuxt 3` (如果网站需要百度/谷歌搜索排名，或首屏加载极速)
- **[ ] 数据可视化：** `ECharts` (配合 `vue-echarts` 封装)
- **[ ] 跨平台/小程序：** `uni-app` (如果需要一套代码同时生成 H5、微信小程序、App)
